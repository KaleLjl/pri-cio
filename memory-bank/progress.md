- **What Works (Implemented Features - Functional Status & Details Verified via Code Analysis):**
  - **Core Structure:** Next.js App Router setup, Layout Wrapper (`src/components/layout/LayoutWrapper.tsx`), Navigation (`Navigation.tsx`), Footer (`Footer.tsx`).
  - **Authentication:** NextAuth.js setup (`/api/auth/[...nextauth]`) with Google & Credentials providers, MongoDB adapter (`@auth/mongodb-adapter`), JWT strategy. Includes API routes for signup, reset password, verify email/code.
  - **User Profiles (`users` collection & `UserService`):**
    - Data structure (`UserProfile` in `src/lib/types/user.ts`).
    - Profile editing via `/api/editprofile` (GET, POST, PUT, DELETE) now uses `UserService`, which handles `users` collection updates and S3 avatar management.
    - Fetching own profile via `GET /api/users/me` now uses `UserService`.
    - Fetching other users' public profile via `GET /api/users/[userId]` now uses `UserService`.
    - Frontend hooks (`useProfilePage`, `useHistory`) updated to align with API changes (FormData for POST, correct GET endpoint).
    - Frontend components (`CurrentUserContext`, `Navigation`, `ChatHistory`) updated to handle API changes and authentication status more robustly.
  - **Explore Page (`/explore` & `/api/explore` & `ExploreService`):**
    - `GET /api/explore`: API route calls `exploreService.getExploreItems`.
    - `POST /api/explore`: API route calls `exploreService.publishItem`.
    - `DELETE /api/explore`: API route calls `exploreService.unpublishItem`.
    - Frontend (`Explore.tsx`, `useExplore` hook) displays items, handles filtering.
  - **Item History (`histories` collection):**
    - `POST /api/history`: API route calls `historyService.createHistoryItem`.
    - `GET /api/history`: API route calls `historyService.getHistoryForUser` to fetch items.
  - **Chat System (`conversations`, `messages` collections):**
    - Real-time via dedicated Socket.IO server (`src/server/socket.ts` - no DB interaction).
    - **Conversation Management (Refactored):**
      - `POST /api/chat/conversations/initialize`: API route calls `conversationService.initializeConversation`.
      - `GET /api/chat/conversations/list`: API route calls `conversationService.listConversations`.
      - `PATCH /api/chat/conversations/settings`: API route calls `conversationService.updateConversationSettings`.
    - **Message Management (Refactored):**
      - `POST /api/chat/messages`: API route calls `messageService.sendMessage`.
      - `GET /api/chat/messages`: API route calls `messageService.getMessages`.
    - `PATCH /api/chat/messages`: API route calls `messageService.markMessagesRead`.
    - `PUT /api/chat/messages`: API route calls `messageService.updateMessageStatus`.
    - `DELETE /api/chat/messages`: API route calls `messageService.deleteConversation`.
    - Structured "Object Discussion" feature within messages (`ObjectDiscussionData` type).
    - **Frontend:** Refactored `Chat.tsx` into sub-components (`ChatHeader`, `UserPostsDisplay`, `MessageList`, `MessageItem`, `ObjectDiscussionCard`, `MessageInput`, `MyPostsPopup` in `src/components/main/chat/`). Logic managed by custom hooks (`useInitializeChat`, `useChatData`, `useChatUI`, `useMessageActions`, `useObjectDiscussion`).
  - **Item Dealing (`dealing` collection & related APIs):**
    - **Initiation:** `POST /api/chat/messages` now upserts a record into `dealing` (status: 'pending') when the first `object_discussion` message for an item is sent.
    - `GET /api/chat/deal`: API route calls `dealService.getDealingItemsForUser` to fetch items for the "Dealing Items" tab in History (reads from `dealing`, joins `histories`).
    - `PATCH /api/chat/deal`: API route calls `dealService.updateDealingStatus` to update dealing status from History page.
    - `POST /api/chat/deal`: API route calls `dealService.completeDeal` upon chat completion to update `histories`, `explore`, and `dealing` collections.
  - **AI Integration (`/api/ai/chat`):**
    - Proxies requests to OpenAI API (GPT-4 Vision/GPT-4).
    - Handles image upload/URL for initial analysis, continues conversation for refinement.
    - No direct database interaction.
  - **Post Creation (`/createpost`):**
    - UI for item details, image upload.
    - Uses `useUpload...` hooks extensively.
    - Triggers `POST /api/history` to save item.
    - Triggers `POST /api/ai/chat` for AI analysis.
  - **History Page (`/history`):**
    - Fetches data via `GET /api/history` and `GET /api/chat/deal`.
    - Client-side logic categorizes items into Saved, Posted, Dealing tabs.
    - Allows deal completion/cancellation via `PATCH /api/chat/deal`.
  - **Database:** MongoDB (`pri-cio` database) connection via `lib/mongodb.ts`. Collections: `users`, `histories`, `explore`, `conversations`, `messages`, `dealing` (plus NextAuth).
  - **File Uploads:** AWS S3 integration via `lib/s3.ts` used by `/api/history` and `/api/editprofile`.
  - **Utilities:** Context providers, custom hooks, type definitions (`src/lib/types`).
  - **Analytics:** Vercel Analytics & Speed Insights integrated.
